Minecraft JS

A 2D Minecraft world built with HTML, CSS and JavaScript. Pick a tool, collect blocks and build your own world.

Start Playing

How to Play

  1. Click a tool in the toolbar. The selected tool becomes highlighted.
  2. Click a tile in the world.
  3. If the tile type matches your tool, the tile is removed from the world.
  4. The removed tile goes to your inventory.
  5. Click a tile in your inventory, then click an empty sky spot to place it back.

The Tools

→

Axe

Removes tree tiles.

→

Pickaxe

Removes rock tiles.

→

Shovel

Removes dirt tiles.

Rules

  • Each tool can only remove its own tile type.
  • Grass cannot be removed.
  • Tiles from the inventory can only be placed on empty sky spots.
  • The Reset World button brings the world back to how it started.
